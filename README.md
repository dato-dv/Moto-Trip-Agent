# Moto-Trip-Agent

ეს პროექტი წარმოადგენს (LLM) დაფუძნებულ ხელოვნური ინტელექტის აგენტს, რომელიც ეხმარება მოტომოგზაურებს მოგზაურობის უსაფრთხოდ და ოპტიმალურად დაგეგმვაში.
# რა ფუნქციები აქვს 
1.ამინდის შემოწმება
2.მანძილისა და საწვავის კალკულატორი
3.უახლოესი ლოკაციის ძებნა(მოტო-სერვისი, ბენზინგასამართი სადგური, სასტუმრო)
4.ბარგის სია(მოგზაურობის ხანგრძლივობის და ამინიდს მიხედვით აგენტი შეადგენს წასაღები ნივთების სიას)

# PEAS
P შესრულების საზომი - როგორ ვაფასებთ აგენტის წარმატებულად მუშაობას ?
ჩვენს შემთხვევაში თუ სწორად შეამოწმა ამინდი, სწორად დათვალა მარშუტი, სწორად მოძებნა ლოკაციები და გვითხრა ბარგის სია ე.ი აგენტმა კარგად იმუშავა.

E გარემო - სად და რა პირობებში მუშაობს აგენტი ?
მისი გარემო არის ჩატი სადაც მომხმარებელი ელაპარაკება და იყენებს ინტერნეტს სადაც ინფორმაციას იძიებს.

A ატუატორები - როგორ გვეკონტაქტება ?
აგენტი პასუხს გვიბეჭდავს ეკრანზე.

S სენსორები - როგორ იგებს რა გვინდა ?
აგენტის სენსორით(ტექტსტით) ხვდება რა გვინდა.

# გარემოს თვისებები
1.ნაწილობრივ დაკვირვებადი: აგენტს არ აქვს სრული ინფორმაცია რეალური სამყაროს შესახებ, იგი ეყრდნობა მხოლოდ მომხმარებლის მიწოდებულ ტექსტს და API მონაცემებს.
2.სტოქასტური: გარემო ცვალებადია (მაგ. ამინდი ან ქსელის ხარვეზები), შესაბამისად შედეგი ბოლომდე წინასწარ პროგნოზირებადი არ არის.
3.თანმიმდევრული: მიმდინარე გადაწყვეტილება (მაგ. საწვავის დათვლა) დამოკიდებულია წინა ნაბიჯზე (მანძილის გაგებაზე).
4.დინამიური: სანამ აგენტი გადაწყვეტილებას იღებს, გარემოს მონაცემები (მაგ. ამინდის პროგნოზი) შეიძლება შეიცვალოს.
5.დისკრეტული: აგენტი პასუხობს კონკრეტული, ცალკეული ტექსტური ნაბიჯებითა და ბრძანებებით.
6.ერთაგენტიანი: სისტემაში მოქმედებს მხოლოდ ერთი აგენტი.
7.ცნობილი: აგენტისთვის ცნობილია თავისი ხელსაწყოების (Tools) მუშაობის წესები და ლოგიკა.

# რომელი ტიპის აგენტია
ჩვენი აგენტი არის Goal-based Agent (მიზანზე დაფუძნებული აგენტი) აგენტს აქვს თავისი მიზანი შეადგინოს სრული და უსაფრთხო გეგმა რისთვისაც იყენებს შესაბამის ხელსაწყოებს.
